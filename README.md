# To Do List Backend

## Requisitos
- Node.js LTS
- MongoDB

## Instalar dependencias

npm install

## Ejecutar MongoDB

mongod

## Ejecutar proyecto

npm start

GET

/getGoals

POST
/addTask
/addGoal

DELETE
/removeTask/:id
/removeGoal/:id
